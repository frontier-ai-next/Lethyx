# Memory Graph and Tree

The graph is a proof/conflict/project substrate. It stores typed nodes and edges such as `supports`, `contradicts`, `supersedes`, `contains_file`, `used_in_phase`, and `helped_outcome`.

Graph outputs can support or block promotion decisions, but graph neighbours remain supplemental/archive unless accepted by BKB promotion. The tree layer represents containment paths for projects, ideas, runs, phases, and subtasks.
